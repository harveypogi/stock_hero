# StockHero - Inventory Management System

## About
StockHero is a web-based inventory management
system developed to help manage products,
stock levels, suppliers, and inventory reports.

## Features
- Dashboard
- Product Management
- Category Management
- Stock In and Stock Out
- Supplier Management
- Inventory Reports
- User Management

## Technologies Used
- PHP
- MySQL
- HTML, CSS, JavaScript
- Bootstrap 5
- XAMPP

## Installation and Setup
1. Install XAMPP.
2. Clone or download this repository.
3. Place the project folder inside htdocs.
4. Start Apache and MySQL.
5. Create a database named stockhero.
6. Import the database schema.
7. Configure the database connection.
8. Open the project in your browser.

## Database Setup

1. Open phpMyAdmin.
2. Create a database named stockhero.
3. Select the stockhero database.
4. Go to the Import tab.
5. Select database/stockhero.sql.
6. Click Import.
